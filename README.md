Motorola Sales Dashboard

An interactive Excel Sales Dashboard built using Microsoft Excel to analyze Motorola sales data. The dashboard provides insights into sales, quantity, transactions, customer ratings, payment methods, brands, cities, and monthly trends through dynamic charts, Pivot Tables, and slicers.

🛠️ Tools Used
Microsoft Excel
Pivot Tables & Pivot Charts
Slicers
Data Visualization
📌 Key Features
KPI Cards (Sales, Quantity, Transactions, Average Sales)
Interactive Filters
Monthly Sales Analysis
City-wise & Brand-wise Performance
Payment Method & Customer Rating Analysis
Mobile Model Sales Comparison
